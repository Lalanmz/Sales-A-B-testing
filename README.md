# Sales Performance & A/B Testing Report

A professional Excel-based sales analytics workbook designed to demonstrate end-to-end performance analysis, experiment evaluation, and data-driven decision making.

---

## Project Overview

This repository contains a complete **Sales Performance Report** built entirely in Microsoft Excel. The workbook processes transactional sales data, calculates key performance indicators, evaluates A/B test results, and translates findings into a clear, prioritized action plan.

The report is structured to reflect real-world analytical work typically required in sales operations, performance marketing, and business intelligence roles.

---

## Workbook Structure

| Sheet              | Purpose                                                                 |
|--------------------|-------------------------------------------------------------------------|
| **Sales_Data**     | Raw transactional data (619 records) with calculated conversion rate and average ticket size |
| **AB_Tests**       | Detailed results of two controlled experiments, including uplift, statistical significance, and recommendations |
| **KPI_Dashboard**  | High-level performance overview with product and channel-level breakdowns |
| **Monthly_Report** | Month-over-month performance summary and key business insights          |
| **Action_Plan**    | Prioritized roadmap of optimization initiatives based on test outcomes and KPI gaps |

## Key Capabilities

---

## Methodology

The report was constructed using standard Excel best practices:

1. **Data Layer (`Sales_Data`)**  
   All transactions were organized in a flat, analysis-ready format. Conversion Rate and Average Ticket Size were calculated using simple, transparent formulas.

2. **Experiment Layer (`AB_Tests`)**  
   Test results were structured for easy comparison. Conversion rates and relative uplift were computed with formulas. Winning variants were highlighted for rapid interpretation.

3. **Aggregation Layer (`KPI_Dashboard` & `Monthly_Report`)**  
   Overall and segmented metrics were generated using `SUM` and `SUMIF` functions, enabling flexible filtering and breakdowns by product and channel.

4. **Decision Layer (`Action_Plan`)**  
   Insights from A/B tests and performance gaps were converted into a prioritized list of initiatives (P0 / P1) with clear ownership and expected impact.

## Sample Business Insights

- Personalized product recommendations delivered a material lift in conversion rate compared to the standard approach.
- Multi-channel follow-up (WhatsApp + Push) outperformed single-channel SMS communication.
- Physical stores maintain higher conversion rates than the online channel.
- Furniture category shows high average order value but relatively low conversion — indicating an opportunity for improved lead qualification and sales process optimization.

## How to Use This Workbook

1. Open the file in Microsoft Excel (or compatible spreadsheet software).
2. Begin with the **Sales_Data** sheet to understand the underlying transactions.
3. Review the **KPI_Dashboard** for a consolidated performance view.
4. Examine the **AB_Tests** sheet to evaluate experiment outcomes.
5. Consult the **Monthly_Report** and **Action_Plan** for conclusions and recommended next steps.

All metrics are formula-driven. Updating records in the `Sales_Data` sheet will automatically refresh dependent calculations across the workbook.
